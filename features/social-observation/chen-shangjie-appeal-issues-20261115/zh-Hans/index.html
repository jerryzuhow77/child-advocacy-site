本案的核心，不只在于社工是否应负责，而是：在关键时间点，谁掌握了哪些讯息、谁能联系哪些人，又能采取什么措施。

阅读三方联系

三方联系的枢纽

能同时联系、追问与传递讯息的人，为什么重要？

依现有资料，能在关键时点同时联系亲属与保母、追问孩子状况并传递讯息者，实际上主要是陈尚洁。这使「完全没有保证人地位」的主张面临困难。

但三方联系不等于当然有罪。法院仍须检验：她当时能取得什么资讯、可促成何种行动，以及该行动是否可能在死亡前降低危险。

法律界线

不是保证不发生死亡

保证人地位不是二十四小时、无限责任的承诺。它要求的是：在已知或应知具体风险、且具有合理处置空间时，是否采取必要行动。

有保证人地位，不等于当然有罪；仍须证明可作为性与结果避免可能性。

一、案件與程序定位

既有整理資料顯示：本案二審為臺灣高等法院115年度上訴字第4688號；2026年11月6日進行的是第二次準備程序，重點在於整理爭點、證據調查、函調／函詢與鑑定聲請，而非終局宣判。

各文件記載，一審就過失致死部分判處有期徒刑2年，偽造文書部分判決無罪；檢辯雙方均提起上訴，二審尚未作成判決。對一審案號、庭期及任何裁示，仍宜以法院正式資料核對。

在現有資料的問題設定中，案件不是重新判斷保母是否施虐，而是判斷未親自施虐的收出養社工，於接觸或掌握孩子異常資訊時，是否負有特定防止義務；若未採取措施，死亡結果能否在刑法上歸責於她。

二、爭點總覽：法院最後必須逐項回答的問題

1. 義務來源：被告是否因法律、契約、職務內容、機構內部分工、實際承接的個案關係、先行行為或特別關係，而對孩子負有特定作為義務？

2. 義務內容：即使存在一般性的專業期待，具體義務究竟是查證、提高訪視、通報、促成就醫、轉介、調整照顧安排、督導，還是其他措施？義務的觸發條件與範圍如何界定？

3. 資訊與預見：被告實際已知、依職務可得知或合理應注意的異常訊息為何？於行為當時，這些訊息是否足以要求提高查證或啟動風險處置？

4. 權限與可期待性：被告能否自行決定、促成或通報相關措施？若需透過其他機關、督導或照顧體系，實際協作與升級處理機制為何？

5. 結果避免可能性：若被告在特定時間採取特定措施，是否具有相當可能使保護系統介入並降低或阻斷危險？不能只以「可能有疏失」取代此一反事實判斷。

6. 因果與客觀歸責：假設的可作為措施、風險實現與死亡結果之間是否存在刑法上的因果關係與客觀歸責？該結果是否正是義務規範欲防止的風險？

三、不作為犯與保證人地位

刑事上的不作為責任，並不因「沒有做事」而自動成立。必須先能指認一項具體作為義務，才可討論未作為是否等同於造成結果。現有法律導讀與程序整理均將「保證人地位」列為本案起點。

辯方的核心線索是：收出養社工的職稱本身不足以推定刑責。法院應檢視其法定、契約及職務義務，所接觸的個案資訊、實際授權、可動用的資源、向上通報與跨單位協作條件，不能以結果發生後的角度補足義務前提。

與此相對，一審認定／檢方方向所關切的是：如果被告已接觸到足以顯示孩子可能有危險的訊息，且其工作角色具有訪視、聯繫、轉介、督導或通報能力，制度分工未必能排除在具體情狀下的注意義務。

四、保證人地位的五步檢驗

保證人地位不是「社工」或「機構受政府監督」的同義詞；它要求把抽象的制度期待，還原為被告在特定個案、特定時間點可被證明的防止結果義務。以下五步須連續成立，任何一環不足，都不能只憑結果回填。

1. 義務來源：須指明義務究竟來自法律、契約、職務說明、個案分派、督導指示、明確自願承擔、危險前行為，或其他足以形成特別保護關係的事實。僅有機構受許可、具有一般服務職能，並不足以當然證明個別員工負有防止死亡結果的義務。

2. 義務個人化：機構的收出養服務義務必須透過具體分工落到被告本人。應以個案主責範圍、工作紀錄、回報節點、督導關係、是否負責聯繫照顧者或安排後續服務加以檢驗，而不能將法人義務不經證明地轉嫁為個人刑責。

3. 保護支配與實際控制：關鍵不在於被告能否單獨把孩子帶離或強制更換照顧安排，而在於其對風險資訊、照顧安排與保護資源是否有足以改變風險的實際影響力。例如能否查證、要求回覆、向督導升級、促成就醫、通報或啟動跨機關協作；各措施的法源、流程與可行性都要分別證明。

依既有文件所載，若在關鍵時點能同時與親屬及保母聯繫、追問並傳遞孩子狀況者實際上只有陳尚潔，則此一「三方聯繫樞紐」事實將使其更難主張完全不具保護支配或具體防止義務。它可支持義務個人化及實際控制的討論，但仍須由卷證逐一確認聯繫的時點、可取得資訊、可促成的措施與可能效果；不能只憑可聯繫，即跳過作為可能性與結果避免可能性的證明。

4. 資訊與觸發：保證義務即使存在，也要看被告當時實際知道什麼、依職務合理應取得什麼，以及這些資訊是否已使合理專業者必須提高查證或處置。不得以孩子後來死亡反推當時必然已知風險；但也不能把尚未親眼確認虐待，直接等同於沒有任何風險處置義務。

5. 反事實因果：最後仍須具體提出「如果當時採取何種措施，會經由何人、何程序、在何時間內使醫療或保護系統介入」，並檢驗是否具有相當可能避免或降低危險。保證人地位不是終點；它只是進入不作為因果與客觀歸責判斷的門檻。

就本案的攻防而言，檢方／一審方向若要主張保證人地位，須以卷證連結上述五步，而非僅以職稱、一般專業期待或機構身分概括推定。辯方則可逐一爭執義務來源是否適用、分工是否已個人化、被告是否有實際影響風險的權限、資訊是否足以觸發處置，以及特定措施是否可能避免結果。最終仍由法院依已調查證據判斷，不能由專家鑑定取代法院作成法律結論。

五、作為可能性與避免死亡結果的具體鏈條

「可以做什麼」必須從抽象選項變成可檢驗的行動鏈：被告在何一時間點取得何種風險資訊；依其權限可以採取何項措施；該措施會送達何人或機關；對方依既有流程可能作何處置；以及該處置能否在死亡前促成就醫、增加保護、改變照顧安排或以其他方式降低危險。

因此，不能只寫「若有通報即可避免死亡」，也不能只因被告沒有強制安置權便否定所有作為可能。應就查證、提高訪視、要求或協助就醫、向督導升級、通報主管機關、轉介保護服務及協作處置逐項比對：當時是否依法可行、是否有時間實施、是否可能被接手，以及其對阻斷危險的具體影響。只有這條反事實鏈經卷證與專業資料支持，才可進一步討論不作為與死亡結果間的刑法因果關係。

比較案例：托兒所主任案（臺灣高等法院110年度上訴字第3736號）

本案裁判資料已核對為臺灣高等法院110年度上訴字第3736號，裁判日期為111年11月8日；原審為臺灣士林地方法院110年度訴字第62號。以下關於具體經過與攻防，仍以現有提供摘要為基礎，待取得裁判全文後逐段核對。此案可用來說明一項關鍵命題：即使某人對照顧現場具有保證人地位，也不等於必須對死亡結果負嚴格責任。依提供者摘要，主任曾對主責保母先前的危險照顧行為告誡並向上回報；但事發僅約十六分鐘，主任同時監督多間教室並處理行政工作，未被期待分秒持續監看監視畫面。二審因此聚焦於其當時是否仍有可期待的介入機會，而非僅以主任職稱或監督關係推定有罪。

此案例與陳尚潔案的相似處在於：兩人都不是直接造成死亡者，且都可能被放在「對他人照顧行為是否負有防止義務」的問題下檢驗。它提醒我們，保證人地位、注意義務違反、作為可能性與結果避免可能性是四個不同問題；保證人地位縱成立，仍必須證明被告在行為時有可期待、可實行而未實行的具體措施。

但兩案不能直接類推。主任案的關鍵事實是直接監督範圍、先前告誡與回報、現場可視性、十六分鐘的事發窗口及行政負荷；陳尚潔案則須獨立釐清其個案角色、取得異常資訊的時間與內容、對保母或照顧安排的實際影響力、督導與通報流程，以及每一項可能措施能否在死亡前啟動保護或醫療介入。

因此，若陳尚潔案的保證人地位最終被認定存在，主攻仍不應是「社工必須二十四小時保證個案安全」，而是有邊界地檢驗：她在非執勤、休假或不知悉危險時是否本就無作為義務；在已取得具體風險資訊時，工作量、案量、權限與時間是否仍容許合理處置。原審如以「案量適中」支持可期待性，更須說明判斷基礎，包括同期個案數、工作時數、案件複雜度、既有行政負荷、督導與支援資源，並與具體風險處置時點相互對照。

本案例的可用結論是：保證人地位不是「保證不發生死亡」，而是要求在職責範圍與可期待界限內，對已知或應知的具體危險採取合理措施。是否有罪，仍取決於具體義務、資訊、作為可能性及反事實因果均經證明，而不是取決於社工身分本身。

六、注意義務、風險訊號與通報

過失評價的焦點是「應注意、能注意而未注意」。異常訊號不必然代表已經確定虐待；但足以引發風險疑慮的訊號，可能提高查證、通報、轉介、協調保護或促成就醫的要求。評價應回到行為時可得的資訊，而非由死亡結果倒推當時必然明知。

通報義務與刑事責任也須分開檢驗：即使某項行政或專業規範要求風險通報，仍要確認被告是否為義務主體、當時是否掌握足夠訊息、可作為的內容為何，以及未通報與死亡結果是否具有可歸責連結。反過來說，尚未自行確認虐待事實，也不當然代表風險處置毫無必要。

具體待核對的風險處置包括：是否應增加或調整訪視、要求即時就醫、通報主管機關、轉介保護性服務、要求變更照顧安排、向督導升級呈報，或採取其他跨機關協作。每一項都須對應行為時的資訊、權限、流程與可行性。

七、制度分工：不是免責公式，也不是職稱推定

現有文件反覆提及收出養服務體系、地方政府保護性社工、居家托育訪視體系、社福中心與其他兒少保護工作者。爭點在於各角色的法定職責、工作分工、督導關係、資訊流通、通報路徑及緊急介入權限。

辯方主張的方向，是先分清被告是否受居家托育訪視規範拘束，是否擁有保護性服務、緊急介入或持續追蹤的主要職權，以及實際可採取的措施。檢方方向則是，分工的存在只影響義務內容與可期待程度，未必能當然免除一個已知或應知風險者的責任。

本案因此不能只問「誰應負責」；更精確的問題是：在每一個關鍵時間點，誰收到什麼資訊、誰有何種處理權限、誰需向誰轉介或通報、實際是否採行，以及延遲或未處理對風險是否有可檢驗的影響。

八、規範來源與「12點提醒指標」

「兒少虐待臨床表徵12點提醒指標」被列為待釐清資料。應調查其制定背景、法規或行政規範性質、適用對象、行為時的版本與實務運作，以及是否對本案職務角色具拘束力。

這裡的爭點不是指標有無參考價值，而是須區分：臨床辨識提示、行政指引、專業倫理、內部作業規範與可直接作為刑事注意義務內容的規範，各自的法律地位與證明力不同。即便有行政或專業瑕疵，仍須另行證明與結果間的刑事歸責鏈結。

九、調查聲請：每項資料要證明什麼

1. 改定監護相關卷證

辯方聲請向新北地方法院函調與剴剴外婆聲請改定監護有關的卷證。其待證方向是當時家庭監護、照顧安排、相關機關掌握的資訊，以及這些事實與被告可得知資訊、可採措施之間的關聯。

2. 文山居托中心

待釐清被告是否受居家托育訪視規範拘束；她與居托體系的分工、督導、通報及資訊流通關係為何；行為時的實務運作是否與規範文字相符。關鍵不只是「有無規範」，還包括規範適用的主體與範圍。

3. 樹鶯社福中心

待釐清社福中心、收出養社工及其他兒少保護工作者的權責、分工與監督關係，特別是誰具有保護性服務、緊急介入及持續追蹤的主要職權，以及個案資訊如何流通。

4. 衛生福利部與12點提醒指標

待釐清指標的制定、版本、適用角色、規範性質與行為時實務。這可用於檢驗風險識別與注意義務的基礎，但不當然直接決定刑責。

5. 機構內部制度與個案資料

待調取或釐清的內容包括：實際工作分工、個案督導、督導鏈、內部通報及升級流程、訪視與聯繫紀錄、是否曾要求或安排就醫、是否曾轉介或採取其他處置。這些資料直接關係到被告的實際責任範圍、可得資訊與可作為能力。

十、法律鑑定與社工專業鑑定

辯方希望以法律鑑定釐清不作為犯、保證人地位、注意義務來源、結果迴避可能性與刑事歸責，並以社工專業鑑定說明收出養服務、居托體系與保護性社工在實務上的分工及合理專業期待。

法院處理方向（依既有整理）是：鑑定不能取代法院決定有罪無罪，也不能取代法院對證據能力、證明力及法律效果的判斷；欲啟動鑑定，須先具體化命題、待證事實、現有卷證何以不足，以及鑑定與本案的關聯。

檢方對必要性的質疑是：若既有事證已足以呈現被告工作內容、資訊與應處作為，新增函調、函詢或鑑定可能只是重複調查或延宕程序。真正需對焦的是每一聲請能補足哪一個不能由現有卷證回答的要件。

十一、雙方攻防的結構對照

辯方主張的完整鏈條是：先確認制度與職務分工，再確認被告是否為義務主體、取得何種資訊、具備何種權限及可採行何種措施；即使存在義務，仍須證明採取措施高度可能避免結果。

檢方／一審方向的完整鏈條是：異常訊息是否已累積至合理專業者應提高警覺、查證、通報、就醫、增加訪視、轉介或介入；若被告已具資訊與能力，不能單以分工界線排除注意義務。

法院待決的問題則是：上述鏈條中每一個環節，哪些已由卷證充分證明、哪些仍需調查、哪些適合鑑定，以及調查的必要性是否大於程序延宕與重複蒐證的成本。

十二、證據與論證地圖

義務來源 → 法規、契約、職務說明、內部制度、個案承接與督導鏈。

資訊與預見 → 訪視、聯繫、通報、醫療與跨單位資訊紀錄；重點是時間點、內容、接收者及回應。

預見可能性 → 不是以死亡結果倒推被告當時必然知道風險，而是依行為時已掌握或依職務合理可得的訊息，判斷合理專業者是否應預見孩子可能面臨具體危險，並提高查證、通報、就醫、轉介或其他處置。它須與資訊來源、角色權限及可採措施一併檢驗。

可作為性 → 被告的授權、資源、通報路徑、向上呈報與跨機關協作能力。

結果避免可能性 → 假設通報、就醫、增加訪視、轉介或變更照顧安排後，是否可能啟動保護機制並避免或降低危險。

刑事歸責 → 義務、風險、可作為性、結果避免可能性與規範保護範圍必須相互連結；單獨存在任一環節不足以直接推出有罪或無罪。

既有文件記載，法院未於本庭就全部函調、函詢與鑑定聲請作最終准駁；辯方須於庭後一個月內具體化法律鑑定命題及相關說明，其餘事項待合議庭評議。下次庭期在既有資料中記為2027年1月8日下午，仍應以法院正式通知為準。

對後續追蹤而言，最重要的是：各函調或函詢是否實際補足義務、資訊、權限或可避免性哪一個環節；鑑定命題是否避免請鑑定人替代法院作法律結論；以及法院如何處理證據調查的必要性與範圍。

十四、規範適用、職務分工與個人義務的逐層檢驗

本節區分「已核實的規範框架」、「待調取的機構內規」與「待證的個案事實」。行政規範、專業手冊或機構制度可用於說明注意義務的內容，但不能跳過保證人地位、實際資訊、可作為性及結果避免可能性的證明。

一、兒少權法的通報義務與觸發門檻

應先核對案發時被告是否屬兒童及少年福利與權益保障法第五十三條所稱的社會工作人員或其他執行兒少福利業務人員；再核對其於執行業務時實際知悉的訊息，是否已達法定通報情形。此一問題不能僅由死亡結果倒推當時已知悉虐待，也不能只因未具居托訪輔身分便排除一切通報、轉介或向上呈報的可能。

二、居家式托育規範的主體與界線

居家式托育服務提供者登記及管理辦法主要規範托育人員與地方主管機關的登記、檢查、輔導及管理。應分辨被告是否為該規範的直接義務主體、居托中心及地方政府是否分別負有訪視或管理任務，以及被告縱非訪輔員，是否仍有透過通報、督導、聯繫或轉介處理風險的實際能力。

三、收出養服務的機構義務如何個人化

兒少權法關於收出養媒合服務者的訪視、評估、輔導、協助與轉介規定，首先配置給經許可的服務機構。待證重點是：案發時有效的職務說明、個案分派、督導鏈、工作紀錄及內規，是否已將其中何種具體任務交由被告承擔；不可將機構的抽象義務直接等同於個人刑事責任。

四、社會工作專業規範的作用與限度

社會工作師法所列的評估、保護性服務、支持性服務與資源轉介，可作為理解專業角色及合理處置選項的材料；但仍應確認被告的資格、實際職務、授權範圍與個案工作內容。專業規範不是以職稱直接推定刑事責任的公式。

五、兒盟內規、手冊與版本效力

應調取案發當時有效的內規、收出養服務手冊、風險辨識指標、教育訓練紀錄、督導與通報流程及個案紀錄，並核對其適用對象、發布與生效日期、是否完成訓練及實際執行情況。事後修訂的制度或手冊可作為改革脈絡，不能倒推為案發時已存在的個人義務。

六、資訊鏈、可作為性與反事實因果

應依時間軸逐一釐清：誰在何時取得何種資訊、訊息來源與可信度為何、是否已轉給督導或其他機關、可採取何種措施，以及每項措施若即時實施，是否具有相當可能促成醫療或保護系統介入並避免或降低危險。此部分須分別檢驗各角色的權限與作為，不能以制度分工或單一行政瑕疵直接推出有罪或無罪。

結論

本案並非只問「社工有沒有責任」，而是要建立一條可由卷證檢驗的完整鏈條：在特定時間點，被告依何種來源負有何種具體義務；她知道或應知道什麼風險；她有沒有可期待且可實施的措施；若採取措施，是否可能避免結果；該結果是否屬於義務規範欲防止的風險。二審的調查聲請與鑑定攻防，正圍繞這些環節展開。
