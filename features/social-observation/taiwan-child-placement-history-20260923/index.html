從「法不入家門」
到家外安置

為什麼親屬未必能靠近孩子？台灣兒少保護制度如何形成，以及王昊與剴剴案留下的改革課題。

中秋水墨紙雕主視覺・穿深藍與淺藍上衣的剴剴非辨識性藝術形象

當孩子進入收出養、安置或替代照顧程序，許多人會問：為什麼最關心孩子的親屬，不能直接把孩子帶回家？為什麼不能自由探視、立即調閱紀錄，或要求更換照顧者？

答案不在於親屬是否關心，而在於孩子一旦進入制度，照顧、監護、探視、資訊與安全決策可能分屬父母或監護人、地方主管機關、法院、收出養媒合服務者及實際照顧者。當權限被分散，誰還持續對孩子的安全負責？

出養同意，不等於放棄孩子的安全。
親屬無法自由探視，也不等於沒有求助、沒有關心。
真正需要追問的是：誰有責任親眼看見孩子、核對異常、啟動通報，並在風險升高時立即改變照顧安排？

一、為什麼親屬對孩子的介入可能有限？

收出養程序的目的，不是讓任何人「擁有」孩子，而是依孩子最佳利益評估：孩子是否確有出養必要、原生家庭能否獲得支持、是否有適合的台灣島內收養人，以及等待期間應如何安全照顧。

依《兒童及少年福利與權益保障法》第16條，父母或監護人若無法盡扶養義務而擬出養，原則上應委託許可的收出養媒合服務者。媒合服務者必須先做出養必要性訪視與評估；若評估不宜出養，應提供或轉介福利服務；若有出養必要，才進入收養人評估與媒合，並以台灣島內收養優先為原則。

因此，親屬的關心不能直接取代法定監護、專業評估或法院程序。孩子處在照顧轉換、媒合評估或高風險期間時，制度可能限制接觸或資訊流通，以避免擅自帶離、衝突、個資外流或再次暴露於未評估的風險。但限制不應成為黑箱。

若親屬被限制探視、不能自由取得孩子資訊，或希望協助照顧卻未被採納，制度就更應留下可追溯的理由、評估依據、期限、替代聯繫方式與複核程序。否則，「保護」可能反而變成沒有人能真正確認孩子狀況的封閉系統。

剴剴是在收出養媒合與等待照顧階段，而非已完成收養。公開資料足以讓社會提出問題；但若沒有完整的監護、交接、訪視與聯繫紀錄，不應逕自斷言每一次限制的法律依據或每位親屬的具體權限。

應當釐清的五件事

  1. 當時誰具法定監護與日常決策權？
  2. 親屬提出探視、照顧或協助時，誰受理、如何評估、是否留下紀錄？
  3. 孩子的照顧安排在法律與行政上屬於何種性質？
  4. 誰負責定期親見孩子、整合傷勢與異常？
  5. 當親屬反映擔憂或希望接回時，是否有風險升級與替代照顧評估程序？

二、1980年代：孩子被困在「家務事」裡

1973年，台灣制定《兒童福利法》，這是兒童福利立法的重要起點。但早期制度重心偏向救助與福利，對受虐、嚴重疏忽、緊急保護、監護權處理與家外安置，尚未建立完整而可操作的制度。

1980年代，社會仍常以「天下無不是的父母」與「法不入家門」理解家庭。家庭內的暴力、失職照顧甚至虐待，容易被視為私領域；外人介入，反而可能被認為多管閒事。

這不是法律真的從未進入家庭。早年的法律其實深度規範家庭關係，只是常以父權秩序為中心；當妻子或孩子遭受傷害時，「家務事」反而成為外部介入的障礙。制度轉變的重點，是改變法律介入家庭時究竟優先保障誰：從維持家庭權威，逐步轉向保障孩子與受暴者的生命、身體、尊嚴與發展權利。

三、當社工看見危險，卻未必有力量把孩子帶走

1991年，家扶成立全國統一的「2085兒童保護專線」，受理民眾通報的兒虐事件。在政府後續建立113保護專線前，這條專線曾是許多孩子與第一線工作者的重要入口。

家扶保存的早期實務回憶記錄顯示，在1993年《兒童福利法》大幅修正前，社工介入受虐案件時，曾遭遇掌摑、潑糞、放狗攻擊、持刀威脅與砸毀辦公室。這些紀錄呈現的是當時保護工作的現場：不只社會觀念排斥，制度權限與安置資源也不足。

家扶早期兒保社工郭淑美曾回憶一組手足的遭遇：長女無法正常上學，年幼手足則生活在嚴重疏忽與髒亂環境中。她曾設法聯繫生父與親屬，希望為孩子尋找寄養等替代照顧；但在家庭強烈抗拒與制度尚未成熟下，始終無法及時完成保護。後續一名幼兒死亡，另一名幼兒遭嚴重傷害，直到警政力量介入才得以帶離。

兒少保護的難題從來不只是「有沒有人發現」，而是發現之後能否進入家庭、能否合法帶離、是否有安全安置資源，以及是否有人能替孩子做急迫的醫療與照顧決定。

家扶及其他民間力量後續發起連署與倡議，獲得約14萬人響應，成為推動1993年《兒童福利法》翻修的重要社會動能之一。

四、1993年：孩子的命，真的等不得

1992年底，家扶協助的棄嬰張靜因心臟病急需手術，卻一度因找不到可合法簽署同意書的監護人而無法及時處置。1993年2月《兒童福利法》修正通過後，張靜成為得以完成監護權移轉、進入手術程序的孩子之一；她最終仍未能存活。

這個事件說明：即使孩子已被發現、醫療資源已在眼前，若法律與行政程序無法讓人及時替孩子作決定，救援仍可能被卡住。孩子的命，真的等不得。

1993年修法後，台灣逐步建立較明確的兒童保護制度：

  • 將兒童最佳利益作為重要處理原則；
  • 建立責任通報；
  • 賦予主管機關保護、安置與必要處置的法源；
  • 建立監護權處理機制；
  • 發展寄養、機構安置與緊急庇護等家外照顧資源。

這是台灣從「勸家庭改善」走向「孩子有立即危險時，國家可以介入保護」的重要轉折。

五、1998年：家暴不再只是家務事

1993年鄧如雯案讓社會正視長期家庭暴力的封閉性。受暴者即使想離開，也可能遭威脅、追蹤、控制；與暴力環境共同生活的孩子，同樣可能長期處於恐懼與危險中。

婦女團體持續推動家暴防治立法。1998年，立法院三讀通過《家庭暴力防治法》；1999年制度正式施行，建立保護令、緊急保護與監督探視等機制。

家庭不是法律不能進入的黑箱。
當暴力危及生命、身體與自由，國家有責任介入。

對兒童而言，這也改變了「父母怎麼管教都屬私事」的觀念。兒童不是家庭財產，而是享有生命、發展與免於暴力權利的個人。

六、王昊案：司法系統不能只處理大人

2011年，幼童王昊遭生母同居人及吸毒友人嚴重虐待致死。案件讓社會看見一個長期被忽略的風險：當父母、監護人或實際照顧者因毒品案件被通緝、羈押、勒戒、強制戒治或入監時，司法系統處理的是大人的案件；但孩子可能同時失去穩定照顧，甚至被交給未經評估的高風險照顧者。

王昊案後，2012年增訂《兒童及少年福利與權益保障法》第54條之1，俗稱「王昊條款」。其核心是：在特定涉毒照顧情境中，司法警察、檢警與法院必須查訪孩子的生活與照顧狀況；若發現受虐或未獲適當照顧，應通報地方主管機關。

王昊條款的主動防線

  1. 不只問成年人是否被羈押或入監；
  2. 也要確認他照顧的孩子現在由誰照顧；
  3. 評估替代照顧者是否安全；
  4. 必要時通報、訪視、提供家庭支持或啟動保護安置。

仍不能停在法條上

同年，刑法第286條也擴及保護未成年人的「身心健全或發育」，不再只侷限於身體自然發育。但有了查訪義務，不代表孩子自然安全。若沒有足夠人力、跨系統資料銜接、實地訪視與後續追蹤，法律仍可能停在紙上。

七、剴剴案：進入制度，不等於已經安全

剴剴案讓社會看見的是更複雜的制度交界。剴剴進入的是收出養媒合與等待照顧階段；這段期間涉及地方政府、收出養媒合服務、實際照顧者、居家托育訪視、醫療辨識與親屬聯繫等多個系統。

當孩子被交給制度安排時，親屬未必能自行帶離、自由探視、調閱紀錄或改變照顧地點。這不表示親屬不關心，更不應倒過來責怪外婆或其他親屬。

真正必須追問的是

  1. 誰具法定權限與日常決策責任？
  2. 誰定期親眼見到孩子？
  3. 誰整合傷勢、外觀、體重、情緒、醫療與照顧異常？
  4. 親屬的求助與希望協助照顧，是否能進入正式評估？
  5. 風險升高時，誰有權也有義務立即改變照顧安排？

剴剴案不是要把所有寄養、居家托育、親屬照顧或收出養媒合概括為不安全；它揭示的是，每一種安排都必須有持續、可查核、可升級的安全責任。

八、剴剴案後：哪些改變已經施行？

剴剴案後，衛福部已推動若干行政調整：

  • 自2024年5月起，兒少出養的必要性評估改由地方政府人員優先介入。
  • 出養兒少若有安置需求，地方主管機關應依法協助安置。
  • 居家托育訪視採不預約、不同時段與親見兒童原則。
  • 對全日托、夜間托育與3歲以下幼兒，加強訪視與風險辨識。
  • 強化托育訪視輔導員、督導與收出養媒合社工的訓練。
  • 對脆弱家庭子女、政府委託安置及出養兒童，結合幼兒專責醫師進行健康與照顧關懷。

共同方向是：不能只看照顧者說明，也不能只完成例行紀錄；必須真正親眼看見孩子。

2025年，刑法也增訂與修正對未滿7歲兒童遭殺害、凌虐致死或致重傷的刑罰規範，提高嚴重虐童案件的法律評價與刑責。然而，刑法處理的是悲劇發生後的究責；它無法取代悲劇發生前的訪視、醫療辨識、風險升級、安置品質與督導責任。

九、哪些改革仍未完成？

目前預告中的兒少權法大修草案，擬補強剴剴案所暴露的制度缺口，包括：

  • 明確化地方政府在收出養程序中的角色與責任；
  • 具體化身體暴力、精神暴力、疏忽照顧與性不當對待；
  • 補強替代性照顧的規範；
  • 研議兒少工作證制度，強化接觸兒少工作者的資格與不適任篩檢；
  • 重新整理兒少保護、福利與兒童權利公約架構。

這些兒少權法改革目前仍屬草案或研議方向，並非已全面生效。
兒少工作證也尚不能直接等同澳洲完整的 Working with Children Check 制度。

改革是否有效，最終仍取決於地方政府人力、訪視頻率、督導品質、跨系統資料整合，以及風險升高時能否真正啟動安置與司法監督。

十、從王昊到剴剴：制度真正需要學會的是主動看見

王昊案讓制度學會：處理涉毒、羈押與入監的成年人時，不能忘記他所照顧的孩子。剴剴案則要求制度再往前一步：孩子進入收出養、托育或任何制度安排後，也不能假定他已經安全。

台灣兒少保護制度真正的進步，不應只是法條變多、刑罰變重，而是每一個高風險孩子都能被持續看見：

  • 看見孩子，不只是看見表格；
  • 看見傷勢，不只是接受照顧者的說明；
  • 看見親屬的求助，不是把責任推回親屬；
  • 看見風險升高後，立即有人有權限也有義務採取行動。

家外安置不是把孩子換到另一個地址。
它是國家接手一條持續保護鏈的承諾：
孩子被交出去的每一天，都必須有人負責確認，他還安全。
