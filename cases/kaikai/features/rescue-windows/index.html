斷點：資訊主要由實際照顧者描述，缺少第三方無預警確認。

轉托後最初幾日是建立基準狀態的窗口。直接看見孩子、核對睡眠與進食、檢查照顧空間，能避免後續所有判讀只剩保母單方描述。

斷點：現有公開整理不足以證明轉托初期已完成獨立、無預警的安全確認。

區間節點待正式紀錄

三次訪視期間：看見孩子，而非只聽見說法

粘羽涵證述居托制度可採無預警訪視，拒訪或異常可升級處理。每一次訪視都能交叉詢問、檢查生活空間，並將前後狀態量化比較。

斷點：陳尚潔的了解高度依賴預約訪視、照片與保母轉述。

115天／三次訪視粘羽涵陳尚潔案一審
06｜2023.10–11

瘀傷與照片：不能只接受單一解釋

多份證詞涉及瘀青、照片與「跌撞」說法。醫療與兒保證人說明，傷勢若與照顧者說法不相符，即存在評估或通報的空間。

斷點：照片被傳遞了，卻未形成直接醫療核實與跨單位閉環。

區間節點許倬憲呂立黃聖心

斷點：照顧者掌握接觸條件，承辦端沒有建立獨立查核管道。

葉亭希、葉詩宇等證詞涉及工作紀錄形成與案後整理；白麗芳、黃玲芳、李芳玲則把問題帶回主管督導、通報門檻與案件討論。案後補寫不當然等於偽造，但即時紀錄不足會讓異常無法累積成正式保護行動。

HOW THE WINDOWS FAILED

十二道門如何逐步失效

照顧端：第一手資訊主要由劉彩萱提供

實際照顧、照片、就醫敘述、探視條件與日常紀錄多由主要照顧者提供。掉牙原因、孩子狀況及最後一夜的相關說法，仍須與牙醫、急診、法醫及其他照顧者證詞交叉核對。

陳尚潔端：獨立查證是否充分

法院已就過失致死部分作出裁判，偽造文書部分無罪；後續法律狀態仍以司法機關公告為準。本頁依證詞檢視：她所取得的保母回報、孩子照片與其他資訊，是否曾充分向醫療端、原照顧者或其他單位交叉確認。

制度端：資訊與權責分散

兒盟、居托中心與政府社工分別具有不同功能及可使用的工具。問題不只在名義上誰是主責，而在警訊出現時，資訊是否送達能夠查證、加訪、通報或調整照顧安排的角色。

結果：不同角色分別掌握部分資訊

前保母掌握轉托前狀況，牙醫看到掉牙情形，醫療端檢視身體狀態，社工取得照片與回報，主管接觸工作紀錄；這些資訊是否及時被整合，正是本頁要追問的制度缺口。

證據勾稽：公開資料顯示，第一手資訊集中、跨單位資訊分散及獨立查證是否充分，是理解十二道救援窗口為何失效的三個核心問題。
