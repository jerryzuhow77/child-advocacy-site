仍缺少的保護閉環

現有公開資料仍要逐項核對：是否立即親見孩子、查明傷勢機轉、向前保母與醫療端交叉查證、提報督導、加訪或無預警訪視，以及是否評估依法通報或更換照顧者。

不能只歸因於一人

承辦端是否升級是重要問題；兒盟督導與機構是否啟動管理工具、政府社工是否接獲風險資訊、居托中心是否能查核，也應分層檢視。

  1. 法院採用的死亡時間：臺北地院判決新聞稿記載，孩子於2023年12月24日凌晨1時31分許死亡。這是本頁可採用的正式時間基準。
  2. 可確認的醫學界線：救護到場時已無生命跡象的媒體報導，以及到院時體溫24度、無呼吸心跳的黃聖心證詞，支持孩子在到院前已發生心肺停止；醫師所稱「一段時間」不是可換算的分鐘數，也不能據此指定前一晚某個時刻。
  3. 不能只用24度倒推出精確時刻：幼兒體溫會受環境溫度、衣著、營養狀態、休克、量測部位、冷水暴露及急救過程影響。沒有核心體溫連續值、初始心律、屍斑／屍僵、現場溫度、法醫解剖與救護完整資料，不能負責任地反推「幾點幾分已死亡」。
  4. 探索性調查假說：本頁優先勾稽12月23日約22時至119抵達前的餵食、呼吸、報案及急救說法，並將約18時至119抵達前列為擴大調查區間。18時只是回溯紀錄的工作起點，不是醫學推定的最早心肺停止時間；僅憑24度無法排除18時以前已出現嚴重低體溫、失去意識或心肺停止。
  5. 較精確的鑑定需求：應合併119錄音、到場生命徵象、AED心律、ETCO₂或監測資料、體溫量測方法、急診急救紀錄、法醫相驗解剖、現場影音及最後被獨立證實仍有生命反應的時間，建立區間，而非製造單一推測時刻。

本站判讀：現有資料可合理寫成「到院前已心肺停止，正式記錄於1時31分許死亡」；24度不是死亡時鐘，不能單獨推算離世時刻。119抵達前的施救者，以及王豫民是否在場或施救，目前均不能確認。「誰在何時說了什麼」「有無嬉鬧」「是否企圖以行政相驗結案」仍有來源衝突，未取得原始資料前只能列為待查疑點。

HOW THE WINDOWS FAILED

十二道門如何逐步失效

照顧端：第一手資訊主要由劉彩萱提供

實際照顧、照片、就醫敘述、探視條件與日常紀錄多由主要照顧者提供。掉牙原因、孩子狀況及最後一夜的相關說法，仍須與牙醫、急診、法醫及其他照顧者證詞交叉核對。

陳尚潔端：獨立查證是否充分

法院已就過失致死部分作出裁判，偽造文書部分無罪；後續法律狀態仍以司法機關公告為準。本頁依證詞檢視：她所取得的保母回報、孩子照片與其他資訊，是否曾充分向醫療端、原照顧者或其他單位交叉確認。

制度端：資訊與權責分散

兒盟、居托中心與政府社工分別具有不同功能及可使用的工具。問題不只在名義上誰是主責，而在警訊出現時，資訊是否送達能夠查證、加訪、通報或調整照顧安排的角色。

結果：不同角色分別掌握部分資訊

前保母掌握轉托前狀況，牙醫看到掉牙情形，醫療端檢視身體狀態，社工取得照片與回報，主管接觸工作紀錄；這些資訊是否及時被整合，正是本頁要追問的制度缺口。

證據勾稽：公開資料顯示，第一手資訊集中、跨單位資訊分散及獨立查證是否充分，是理解十二道救援窗口為何失效的三個核心問題。
