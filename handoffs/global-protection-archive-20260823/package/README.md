# 全球守護留言牆｜守護文章典藏與舊文再浮現更新包

**版本：** 2026-08-23  
**適用站點：** `cn.globalprotectionwall.com` 與同源的全球守護留言牆前台  
**更新類型：** merge-only 前台功能更新  
**資料安全邊界：** 不變更投稿、登入、審核、回覆、檢舉、會員權限或既有 API。

## 這次解決的問題

貼文數量增加後，單純依發布時間排列會讓過往文章快速沉底。本更新加入「分類、典藏、策展、重新發現、相關閱讀」五層機制，讓新貼文持續向前，也讓舊文章有穩定重回首頁與讀者視線的入口。

## 已完成的功能

1. 首頁每日舊文再浮現：「今天，再讀一篇守護」每日固定輪替。
2. 守護文章典藏館：搜尋、語言、主題、地區、案件與年份交叉篩選。
3. 長期推薦、最新發布、最多互動、重新發現四種排序。
4. 今天再讀、本月值得再讀、你可能錯過的守護三組策展入口。
5. 依主題與案件自動統計的守護書架。
6. 文章內「繼續閱讀這條守護線」相關舊文推薦。
7. 繁中、简中、English、日本語介面與手機響應式導覽。

## Repository-relative 檔案

- `patches/guardian-wall.archive.patch`：元件差異檔。
- `patches/globals.archive.patch`：全域 CSS 差異檔。
- `APPLY_TO_CURRENT_SITE.md`：安全套用、測試與回復步驟。
- `PATCH_MANIFEST.json`：更新範圍與保護邊界。
- `ops/deploy_archive_merge_only.sh`：預設只做 dry-run 的保護式部署助手。
- `VALIDATION_REPORT.txt`：離線驗證結果。

## 重要原則

香港／大陸版正式站比 2026-08-21 基準更新，必須採 **merge-only**。保留正式站現有投稿、照片、會員登入、管理審核、通知、回覆、API、資料庫與 secrets，只合併典藏相關程式與樣式。正式站目前尚未包含典藏標記，且必須取得騰訊雲終端後，從目前線上最新版建立備份、乾跑 patch、build、完整回歸，再決定發布。
