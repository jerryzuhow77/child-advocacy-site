# 護童行動聯盟官網雛形

這是一個純靜態網站，可直接部署至 GitHub Pages、Cloudflare Pages、Netlify 或一般虛擬主機。

## 檔案
- `index.html`：網站內容
- `styles.css`：視覺樣式與響應式排版
- `script.js`：手機版選單與年份
- `assets/logo.png`：網站標誌

## 上線方式
1. 將整個資料夾上傳至網站主機。
2. 網站根目錄必須包含 `index.html`。
3. 綁定正式網域後，啟用 HTTPS。

## 正式上線前建議補充
- 官方電子郵件或聯絡表單
- 隱私權政策、著作權及資料更正機制
- 案件文章資料與來源連結
- 活動紀錄照片及影像授權說明
- Google Search Console 與社群分享縮圖

## 法律與內容提醒
- 不揭露兒少可識別資訊。
- 審理中案件應遵守無罪推定。
- 對個人之指控應有可靠來源，並清楚區分事實、判決認定、陳述與評論。
