萱萱案｜GSAP 動畫強化＋四位人偶各三組新姿勢更新包
版本：2026-08-19 GSAP 1

部署方式
1. 解壓縮後，以壓縮檔內的相同相對路徑覆蓋網站專案。
2. 推送至 GitHub Pages，等待部署完成。
3. 若手機仍顯示舊動畫，請重新整理或清除該頁快取。

本次 GSAP 強化
- 使用 GSAP 3.13.0 與 ScrollTrigger 編排開場、七段幕間及終幕時間軸。
- 布幕開合、戲臺梁柱、五盞燈、人偶進退場、卷宗道具與文字依同一時間軸同步。
- 四位人偶保留原姿勢入場，再以淡出換袖方式切換三組新增姿勢。
- 章節圖片加入低幅度捲動視差，閱讀進度條改用 transform 更新以降低重繪。
- 手機版縮小人偶位移與視差幅度，避免畫面跳動及人物超出舞臺。
- 「重看本幕」會重置為原姿勢後，從頭播放該幕 GSAP 時間軸。
- 尊重系統「減少動態效果」設定；GSAP 或 CDN 未載入時，自動使用原 CSS／IntersectionObserver 備援動畫。
- 繁體中文／簡體中文、英文、日文同步套用相同動畫。

四位角色新增姿勢
- 藍袍守卷人：閱卷、持印、交卷。
- 粉綠袍傳卷人：確認收件、雙手交卷、示意等待。
- 灰袍衡證人：查閱證據、暫停複核、卷宗上秤。
- 紅袍引線人：縫合紀錄、守望提燈、傳遞金線。
